表單下載 優化

三件事：① 使用說明可以展開／編輯　② 下載的檔名　③ 拖拉上傳。還沒動程式碼。

❷ 下載的檔名（這個是 bug，不用挑）

為什麼會是亂碼：現在的下載是把「原始檔名」塞進網址的 ?download=， 伺服器再把它寫進 HTTP 表頭 —— 而中文在那個表頭裡沒有被正確編碼， 瀏覽器就照 byte 讀成一串亂碼。
★★ 所以「改成用表單名稱」單靠換字串是不會好的 —— 「支出證明單」也是中文，走同一條路一樣會亂。
改法：不走那個表頭。把檔案抓下來變成一個暫存連結， 檔名用瀏覽器自己的 download 屬性帶 —— 那是純文字，中文不會壞。
表單名稱原本存的檔名現在下載得到改後下載得到
命名規則（打勾的地方是會被處理掉的）：
  • 檔名 ＝ 表單名稱 ＋ 原本那份的副檔名（.docx／.pdf 照舊，不會換格式）
  • Windows 不准的字元 \ / : * ? " < > | 換成 _ —— 不然存不進資料夾
  • 表單名稱如果已經帶了副檔名（有人會打「請假單.docx」），不重複加
  • 表單名稱空的（理論上不會，它是必填）就退回原始檔名 —— 不要產生一個叫「.docx」的檔

❶ 使用說明可以展開／編輯　—— 這一題要挑

現在列上那一行說明是單行、而且被截斷（「無憑證時使用，填寫產生支出支出證明」寫長一點就看不完）。 你要的是「點開來看完整說明、而且改得動」。差別在要一個欄位還是兩個。
甲　一個欄位（建議）
現在那個「說明」直接變成多行的使用說明。列上顯示第一行，點「使用說明 ▾」展開全部。
★ 一件事一個名字（README 的用語表）。
★ 不用改資料庫 —— note 本來就是 text，長度沒有上限。
乙　兩個欄位
一行短的（列上一直看得到）＋ 一段長的使用說明（收起來）。
★ 代價：上傳的人每次要想「這句話算短說明還是使用說明」，
而寫錯的那幾筆，看的人分不出來 —— 只會覺得有的表單說明很短。
★★ 要多一支欄位，得跑一支 migration。
兩案共通的：對話框裡那一格從單行 input 換成可以換行的 textarea， 權限跟現在一樣 —— 總經理｜會計｜主管改得動，其他人只看得到。

❸ 拖拉上傳

現在那個虛線框本來就是一顆按鈕（點了開檔案選擇器）。 加拖拉不換版面 —— 只是多一種放進去的方式，點一下照樣可以用。 下面三張是同一個框的三個狀態：

三個一定要顧到的：
  • 拖到框外面不可以開啟檔案。沒擋的話拖歪一點，瀏覽器會直接用新分頁打開那個 Word —— 對話框裡填一半的東西全部不見
  • 一次只收一份。拖三個進來就取第一個，並且講一句「一次一份，先放了第一個」
  • 不收的格式在放開的當下就說（.xlsx、.jpg）—— 不要等按了上傳才擋
★ 手機沒有拖拉這回事，點擊那條路完全不變。

這次沒動的

分類（人事／財務／房務／其他）、排序、搜尋、權限（看＝全公司含房務，改＝總經理｜會計｜主管）、 檔案大小上限、列上「編輯／刪掉／下載」三顆的位置與顏色 —— 一個字都不動。
