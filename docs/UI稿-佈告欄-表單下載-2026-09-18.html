佈告欄：多一格「表單下載」＋ 帳密移到最後

分頁點得動、右上角可以切身分看差別、「上傳」按得開。還沒動程式碼。底下有 2 個要你決定的地方。

用誰的身分看

誰可以做什麼

　下載上傳 / 換檔案 / 改名 / 刪除
總經理　super_admin✓✓
會計　　accountant✓✓
主管　　manager✓✓
管家　　housekeeper✓✕
房務　　cleaner✓✕
「其他人有權限可以下載」＝ 全公司都下載得到（含房務）—— 那是這一格存在的意義： 請假單、報帳單這種表單本來就是發給大家填的。
★ 這跟帳密那一格不一樣（房務看不到）。兩格的規則不同，所以是兩支各自的 policy，不共用。
★★ 看得到但不能改的人，畫面上不畫「上傳／換檔案」那些鈕 —— 不是灰掉。 灰掉的鈕會讓人一直點然後問「為什麼我不能用」（跟權限管理頁同一個處理）。
❶ 分頁順序
  • 通知 → 活動 → 表單下載 → 帳密（建議）　上面的稿子就是這樣。 帳密放最後 —— 它是最少點、最敏感的一格。
  • 通知 → 活動 → 帳密 → 表單下載　帳密只往後移一格。
❷ 要不要分類？
  • 要（建議）　人事 / 財務 / 房務 / 其他。表單會越積越多，十份以後沒有分類就只能靠搜尋。 上面的稿子就是這樣。
  • 不要　一條平的清單，靠搜尋找。少一個欄位。

這次不會動到的

通知、活動、帳密三格的內容一行都不動 —— 只有分頁的順序會變。
要一支 migration：新開一張 board_forms（檔名、說明、分類、檔案、誰上傳、什麼時候） ＋ 一個 storage bucket ＋ RLS（全員讀、三種角色寫）。
★ Word 與 PDF 兩種都收，跟「活動」那格同一套（.pdf .doc .docx）。
