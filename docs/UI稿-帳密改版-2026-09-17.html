差在哪

現在　32 張卡全部攤開在同一頁，每一張都印著帳號與密碼欄。要找一個得往下捲很久， 而為了塞得下，字被壓到 11～13px（你說的「字太小」就是這個結果）。

調整後　清單一行一個、字 17px，一個畫面看得到十幾個；點進去才是帳號密碼，欄位用 15px。 字變大而且看得到的東西變多 —— 因為清單那一層不需要印密碼。

★ 翻閱稽核（`board_secret_reads`）照舊 —— 現在改成「點進詳細頁才算翻閱」，比原本一進帳密頁就整排渲染出來合理得多。
❶ 要不要多一個「網址」欄？（Google 那邊叫 Sites）
  • 要（建議）　Zoho 的 https://mail.zoho.com/、591、綠界那些現在只能寫在備註裡。有這一欄就點得開。
    需要一支 migration 加 board_secrets.url。
  • 不要　繼續寫在備註。少一支 migration。
❷ 清單要照什麼排？
  • 照類別（建議）　訂房 → 社群 → 帳號 → 電商 → 物流 → 財稅 → 其他 → 公司資料。上面的稿子就是這樣。
  • 照最近改過的　跟現在一樣（updated_at desc）。剛改過的浮上來。
  • 照名稱　純字母／筆劃排序。
❸ 手機上那兩欄怎麼辦？ 桌機是左右兩欄（帳號密碼｜網址備註）。手機寬度不夠，建議直接疊成一欄（稿子在窄視窗會自己變，你把瀏覽器縮窄看看）。
