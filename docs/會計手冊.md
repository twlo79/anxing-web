# 安幸上工 ERP — 操作手冊

給全體同仁的操作說明。不需要任何技術背景，照著看就會用。

網址：**justwork.estia.com.tw**

## 零、先把手機裝起來

現場記錄和核可請款主要在手機上做，建議裝成 App。

**iPhone**（一定要用 Safari，Chrome 不行）
Safari 開網址 → 下方「分享」→ 往下找「**加入主畫面**」→ 新增

**Android**
Chrome 開網址 → 右上選單 → 「**安裝應用程式**」

裝好後主畫面會出現黑底「安幸」圖示，點開是全螢幕、沒有網址列。

### 開啟核可通知

裝好後從主畫面進入 → 請款填寫 → 最上方「**核可通知**」按「開啟」。

有請款單等你核可時，手機會跳通知。

> **iPhone 特別注意：**一定要從主畫面的圖示進去才看得到這個開關。用 Safari 直接開網頁是沒有的 —— 這是 Apple 的限制，繞不過去。

## 一、這套系統在做什麼

一句話：**把錢進來和錢出去，都變成有紀錄、有憑據、有人負責的動作。**

```
        錢進來                              錢出去
   ┌──────────────┐                   ┌──────────────┐
   │  短租訂單     │                   │   請款單      │
   │  契約(長租)   │                   │  （要花錢）    │
   └──────┬───────┘                   └──────┬───────┘
          │ 系統自動                          │ 核可 → 付款
          ▼                                  ▼
   ┌──────────────┐                   ┌──────────────┐
   │   營收報表    │                   │    支出       │
   └──────────────┘                   └──────────────┘
```

左邊那條是自動的，你只要把訂單記對，營收自己會算。
右邊那條要人簽核，錢花出去之前得有人點頭。

## 二、錢進來：訂單 → 營收

### 你只需要做一件事：把訂單記對

訂單記進系統之後，**營收報表會自己產生，不用另外填**。

```
   你輸入的                        系統自動算的
┌────────────────┐            ┌─────────────────────┐
│ 客戶：王小明     │            │ 8月 營收 $12,000     │
│ 入住：8/28      │  ────►     │ 9月 營收 $18,000     │
│ 退房：9/5       │            │                     │
│ 金額：$30,000   │            │ （按住幾晚，自動分月） │
└────────────────┘            └─────────────────────┘
```

**重點：跨月的訂單會自動拆開。** 上面的例子住了 9 晚，其中 4 晚在 8 月、5 晚在 9 月，系統就按天數把 3 萬元分到兩個月，不用你手算。

### 兩種訂單，兩種記法

| | 短租訂單 | 契約（長租）|
|---|---|---|
| 在哪 | 短租訂單與收款 | 契約訂單與收款 |
| 怎麼進來 | Airbnb 每天自動抓；直客手動新增 | 建一次契約 |
| 特別的地方 | — | **建好契約，每個月的月租單自動長出來** |

契約那邊特別省事：你設定「2026/9/1 到 2028/8/31、月繳 11 萬」，系統就把這 24 個月的收款單一次全部建好，每個月只要去點「本月未收」那顆按鈕收款就行。

### 列表怎麼看

短租和契約的列表都精簡過，只留最常掃視的欄位。

**點任何一列會從右邊滑出詳細資訊**，押金、外幣、備註、發票設定那些都在裡面，編輯和刪除也在那裡。

> **為什麼刪除要藏在裡面？** 短租有 1,900 多筆訂單，刪除如果就擺在編輯旁邊，手滑一下就是一張真實訂單消失。要先點開看到完整內容才刪得掉，那本身就是一道確認。

### ⚠️ 三件要注意的事

**1. 營收報表不能手動改。** 它是系統從訂單算出來的。數字不對，去改訂單，報表會跟著變。直接改報表沒有意義，下次重算就沒了。

**2. 已經打勾「已收款」的月租單，不會被契約異動蓋掉。** 這是保護設計 —— 你改契約的租期或金額，系統只會動還沒收錢的那幾期，已經收到的錢不會憑空變動。

**3. 押金不是營收。** 押金是暫時保管的錢，之後要還，所以不計入營收。系統分開記。

## 三、錢出去：請款 → 核可 → 付款 → 支出

### 完整流程

```
 ①          ②            ③              ④            ⑤
需求     填請款單      主管核可        實際付款      變成支出

「4樓冷氣   在系統裡    ┌─ 主管  ✓ ┐   現金：直接    自動出現在
 壞了」  →  填單送出 → │          ├→  確認支付   →  支出頁
           （可多項）  └─ 總經理 ✓ ┘   匯款/信用卡： （不用再輸入）
                                       先排付款
                       兩個都要點頭     再確認支付
                       （未滿 3000 免核）
```

### 一步一步

**① 需求發生**
房源缺備品、設備壞了、辦公室要買東西 —— 任何要花公司錢的事。

**② 填請款單**（左側選單「🧾 請款填寫」→「+ 填寫請款」）

一張單可以填**很多項目**。買三樣東西不用開三張單。

每個項目要填：

| 欄位 | 說明 | 例子 |
|---|---|---|
| 項目名稱 `*` | 買什麼 | 冷氣濾網 |
| 金額 `*` | 多少錢 | 1,200 |
| 會計科目 | 這筆算哪一類 | 修繕維護 |
| **用途** `*` | **這筆花在哪個物業** | 時兆 |
| 備註 | 補充說明 | 選填 |

標 `*` 的是必填。

然後填**支出方式**：現金 / 匯款 / 信用卡。
選匯款的話，要填**收款方（廠商）**的銀行代碼、帳號、公司名、統編。

> **「用途」是物業層級，不是房源。** 選「時兆」「正隆」這種，不是「時兆A2」。之後看「哪個物業花最多錢」全靠這一欄。
> 不是物業的（辦公室文具、公司保險），選「安幸辦公室」。

**外幣怎麼填？**

幣別預設台幣。刷卡刷到外幣時，把幣別改成 USD / JPY / CNY / EUR，會多出一個**匯率**欄位。

- 金額欄填**原幣別**的數字（例如 USD 100 就填 100）
- 匯率填帳單上的**實際換算率**（1 USD = 31.5 就填 31.5）
- 系統自動算出台幣總額

> 匯率要手動填，系統不會自動抓。你需要的是「刷卡當下那筆的實際匯率」，那只有帳單上才有，自動抓來的反而不準。

填完可以先「儲存草稿」慢慢補，確定了再按「送出審核」。

**③ 核可**

送出後看金額：

```
   總額 < NT$3,000  ──────────────────► 直接通過，不用等

   總額 ≥ NT$3,000  ──┬─ 主管    點頭 ─┐
                      │                ├── 兩個都點頭 → 通過
                      └─ 總經理  點頭 ─┘

                      誰先點都可以，沒有先後順序
```

**兩票都要到齊才算通過。** 只有一個人點頭，還是不能付款。

門檻是看**整張單換算成台幣的總額**，不是單項。三個項目各 1,500 元、總共 4,500 元，還是要核可 —— 這樣才不會有人靠拆單規避。

如果覺得有問題，可以**駁回**並寫原因。單子回到申請人手上，改完可以重新送。駁回後已經投的票會清空，重新來過。

> **主管可以核可自己送的單。** 人手不多的實務考量。但要知道代價：主管送的單，那一票沒有第二個人把關，實際上只剩總經理一道關卡。

**④ 實際付款**

核可通過 ≠ 已經花錢。要等錢真的付出去，才回來登記。

| 支出方式 | 怎麼做 |
|---|---|
| **現金** | 直接按「確認支付」，填實際付款日 |
| **匯款 / 信用卡** | 先「**排付款**」：選預定日期 + 從哪個帳戶匯（或刷哪張卡）<br>錢真的出去後再按「**確認支付**」，填實際日期 |

匯款和信用卡**一定要先排付款**才能確認支付。這是刻意的 —— 不然會發生「錢付了卻不知道從哪個帳戶出去」的情況，而那正是最需要記錄的事。

「確認支付」時會自動帶入預定日期，實際日期不同就自己改。

可以操作的人：**會計、主管、總經理**。

**⑤ 自動變成支出**

按下確認支付的當下，這張單的每個項目**各自變成一筆支出**，出現在支出頁。

```
請款單 PR-202608-003
├─ 冷氣濾網   $1,200  修繕維護  時兆    ──►  支出：8/15 冷氣濾網 $1,200
├─ 遙控器     $  450  備品      時兆    ──►  支出：8/15 遙控器  $  450
└─ 工資       $2,000  修繕維護  時兆    ──►  支出：8/15 工資    $2,000
```

**不用再手動輸入一次。** 付款帳號、幣別、匯率也會一併帶過去。

### 請款頁的畫面

**上排卡片**（該做什麼）：待主管核可 ／ 待總經理核可 ／ 待排付款 ／ 待支付
**下排卡片**（多少錢）：申請總額 ／ 現金 ／ 匯款 ／ 信用卡

**付款排程表**會列出「哪天要從哪個帳戶準備多少錢」，依預定付款日分組。這張表看的是預定付款日，跟上面卡片的建立日是兩條不同的時間軸，所以數字不會一致，那是正常的。

**點任何一列開啟詳細抽屜** —— 完整資訊和所有操作（編輯、核可、駁回、排付款、確認支付、撤銷）都在裡面。列上只留「核可」和「分享」兩個最常用的。

### 分享給主管核可

列上或抽屜裡的「**分享**」按鈕，會把單據資訊整理好傳到 LINE，附上一個**可以直接開到那張單的連結**。

主管從 LINE 點進去，系統會自動跳到那張單並展開抽屜，直接按核可 —— 不用自己在列表裡翻找。

### 撤銷

**還沒付款的單，任何狀態都可以撤銷。** 可以撤銷的人：提交者本人、主管、會計、總經理。

**已經確認支付的單不能撤銷**，因為支出已經產生了。要處理請找總經理。

## 四、支出頁

左側選單「📒 支出」。管家和房務看不到這一頁。

上面三張卡片：

- **總支出** — 目前篩選條件下的總金額
- **會計科目分項** — 錢花在哪些類別（修繕？備品？水電？）
- **物業分項** — 哪個物業花最多

下面是明細，可以照日期、科目、用途、支付方式篩選，也能下載 Excel。外幣的支出會在金額下方顯示原幣別與匯率。

### 兩種支出

| 來源 | 標記 | 能不能刪 |
|---|---|---|
| 請款單連動 | 項目旁有藍色「請款」標籤 | **不能刪**（只有總經理可以）|
| 直接新增 | 無標記 | 可以刪 |

**為什麼連動的不能刪？**

因為那筆錢是走完兩票核可才花出去的。如果一個人就能把紀錄刪掉，那兩道核可等於白設。而且刪掉之後請款單還是顯示已付款，支出這邊卻沒了，**兩邊對不起來而系統不會提醒你** —— 這種帳最難查。

要修正金額請用「編輯」，不要刪。

## 五、誰能做什麼

### 職位與權限

**權限由職位決定，不能單獨改。** 在設定頁改職位，權限會自動跟著變。

| 職位 | 權限 |
|---|---|
| 管家 | 一般 |
| 房務 | 一般 |
| 經理 | 主管 |
| 會計 | 會計 |
| 總經理 | 總經理 |

> 為什麼綁在一起？以前兩欄各改各的，結果會出現「管家職位 + 總經理權限」這種對不起來的組合，而且沒人會發現。職位是人事事實，權限是它的結果。

### 各權限看得到什麼

```
                  訂單  營收  請款  核可  排付款/支付  支出  評價/清潔  設定
   一般    🧹      ✓     ✗     ✓     ✗       ✗        ✗       ✓        ✗
   會計    📗      ✓     ✓     ✓     ✗       ✓        ✓       ✗        ✗
   主管    👔      ✓     ✓     ✓     ✓       ✓        ✓       ✓        ✗
   總經理  🔑      ✓     ✓     ✓     ✓       ✓        ✓       ✓        ✓
```

**一般（管家、房務）**
日常記錄訂單、清潔、看評價。可以請款，但**只看得到自己送的單**，也看不到公司整體的營收和支出。

**會計**
帳務作業。看得到訂單、營收、支出，可以排付款、確認支付、整理支出。

> **會計不能核可請款單。** 這是刻意的 —— 請款的人、核可的人、記帳的人要分開，這樣才叫內控。會計負責「錢花掉之後把帳做對」，不負責「決定要不要花」。

**主管（經理職位）**
核可的其中一票。也能做會計能做的所有事。

**總經理**
核可的另一票，加上人員、物業、房源、帳號等系統設定。

## 六、常見情況怎麼辦

### 「單子填錯了，還沒送出」
直接編輯，或撤銷重開。草稿狀態隨你改。

### 「送出了才發現填錯」
自己撤銷，或請主管駁回。駁回的單會回到你手上，改完重送。

### 「已經核可了才發現金額錯」
核可過的單不能改內容。**但只要還沒確認支付，就可以撤銷重開一張。**

已經確認支付的話，照原本的處理，然後在支出頁調整那筆金額並在備註寫明原因。差額大的話跟主管說一聲，另外開一張單處理。

### 「付款日填錯了」
可以改。改了之後對應的支出日期會跟著調整，**不會重複產生新的支出**。

### 「東西後來沒買」
只要還沒按「確認支付」，直接撤銷那張單就好。

### 「找不到『確認支付』按鈕」
如果是匯款或信用卡的單，要**先按「排付款」**選好日期和帳戶，確認支付才會出現。現金的單沒有這個限制。

### 「我看不到支出頁」
你是一般權限（管家或房務）。支出資訊只開放給會計以上。

### 「核可按鈕點不下去」
兩種可能：你的那一票已經投過了，或你是會計（會計不核可）。

### 「上個月的單找不到」
請款頁預設只顯示**本月**。把上方的「月份」改成上個月，或清空。

### 「營收報表的數字怪怪的」
不要改報表，去看**訂單**。報表是從訂單算出來的，訂單對了報表就對了。

### 「手機收不到核可通知」
三件事確認：
1. 有沒有從**主畫面的圖示**進去（iPhone 用 Safari 開網頁是收不到的）
2. 請款頁最上方的「核可通知」有沒有按「開啟」
3. 手機系統設定裡，這個 App 的通知有沒有被關掉

## 八、三個原則

**1. 用途一定要填對。**
物業分項統計、之後要算單一物業的損益，全靠這一欄。

**2. 系統自動算的東西不要手動改。**
營收報表、契約的月租單、請款連動的支出 —— 這些都是算出來的。要改就改源頭。

**3. 核可是為了保護你。**
兩票核可不是不信任，是讓花錢這件事有紀錄、有人共同承擔。事後有疑問時，單子上寫得清清楚楚是誰在什麼時候點頭的。
