# 安幸上工 ERP — 會計手冊

給全體同仁的操作說明。不需要任何技術背景，照著看就會用。

網址：**justwork.oasisliving.tw**

## 一、這套系統在做什麼

一句話：**把錢進來和錢出去，都變成有紀錄、有憑據、有人負責的動作。**

```
        錢進來                              錢出去
   ┌──────────────┐                   ┌──────────────┐
   │  短租訂單     │                   │   請款單      │
   │  契約(長租)   │                   │  （要花錢）    │
   └──────┬───────┘                   └──────┬───────┘
          │ 系統自動                          │ 主管核可後
          ▼                                  ▼
   ┌──────────────┐                   ┌──────────────┐
   │   營收報表    │                   │    支出       │
   └──────────────┘                   └──────────────┘
```

左邊那條是自動的，你只要把訂單記對，營收自己會算。
右邊那條要人簽核，錢花出去之前得有人點頭。

## 二、錢進來：訂單 → 營收

### 你只需要做一件事：把訂單記對

訂單記進系統之後，**營收報表會自己產生，不用另外填**。

```
   你輸入的                        系統自動算的
┌────────────────┐            ┌─────────────────────┐
│ 客戶：王小明     │            │ 8月 營收 $12,000     │
│ 入住：8/28      │  ────►     │ 9月 營收 $18,000     │
│ 退房：9/5       │            │                     │
│ 金額：$30,000   │            │ （按住幾晚，自動分月） │
└────────────────┘            └─────────────────────┘
```

**重點：跨月的訂單會自動拆開。** 上面的例子住了 9 晚，其中 4 晚在 8 月、5 晚在 9 月，系統就按天數把 3 萬元分到兩個月，不用你手算。

### 兩種訂單，兩種記法

| | 短租訂單 | 契約（長租）|
|---|---|---|
| 在哪 | 短租訂單與收款 | 契約訂單與收款 |
| 怎麼進來 | Airbnb 每天自動抓；直客手動新增 | 建一次契約 |
| 特別的地方 | — | **建好契約，每個月的月租單自動長出來** |

契約那邊特別省事：你設定「2026/9/1 到 2028/8/31、月繳 11 萬」，系統就把這 24 個月的收款單一次全部建好，每個月只要去打勾「收到了」就行。

### ⚠️ 三件要注意的事

**1. 營收報表不能手動改。** 它是系統從訂單算出來的。數字不對，去改訂單，報表會跟著變。直接改報表沒有意義，下次重算就沒了。

**2. 已經打勾「已收款」的月租單，不會被契約異動蓋掉。** 這是保護設計——你改契約的租期或金額，系統只會動還沒收錢的那幾期，已經收到的錢不會憑空變動。

**3. 押金不是營收。** 押金是暫時保管的錢，之後要還，所以不計入營收。系統分開記。

## 三、錢出去：請款 → 核可 → 採購 → 支出

這是新的模組，流程比較長，但每一步都有意義。

### 完整流程圖

```
 ①            ②              ③                ④              ⑤
需求      填請款單        主管核可          填採購日        變成支出
                                                      
「4樓冷氣    在系統裡      ┌─ 主管  ✓ ┐     東西買了、      自動出現在
 壞了」  →   填單送出  →  │          ├→ →  錢付了，      →  支出頁
            （可多項）    └─ Admin ✓ ┘     填上日期        （不用再輸入）
                          
                          兩個都要點頭
                          （未滿 3000 免核）
```

### 一步一步

**① 需求發生**
房源缺備品、設備壞了、辦公室要買東西——任何要花公司錢的事。

**② 填請款單**（左側選單「🧾 請款填寫」→「+ 填寫請款」）

一張單可以填**很多項目**。買三樣東西不用開三張單。

每個項目要填：

| 欄位 | 說明 | 例子 |
|---|---|---|
| 項目名稱 | 買什麼 | 冷氣濾網 |
| 金額 | 多少錢 | 1,200 |
| 會計科目 | 這筆算哪一類 | 修繕維護 |
| **用途** | **這筆花在哪個房源** | 14B5 |
| 備註 | 補充說明 | 選填 |

然後填**付款方式**：現金 / 匯款 / 信用卡。
選匯款的話，要填**收款方**（廠商）的銀行代碼、帳號、公司名、統編。

> **「用途」很重要，請務必填對。** 之後要看「哪個房源花最多錢」全靠這一欄。填錯了帳就歸錯房源。
> 不是房源的（辦公室文具、公司保險），選「安幸辦公室」。

填完可以先「儲存草稿」慢慢補，確定了再按「送出審核」。

**③ 主管核可**

送出後看金額：

```
   總額 < $3,000  ──────────────────► 直接通過，不用等
   
   總額 ≥ $3,000  ──┬─ 主管   點頭 ─┐
                    │               ├── 兩個都點頭 → 通過
                    └─ Admin  點頭 ─┘
                    
                    誰先點都可以，沒有先後順序
```

**兩票都要到齊才算通過。** 只有一個人點頭，還是不能採購。

門檻是看**整張單的總額**，不是單項。三個項目各 1,500 元、總共 4,500 元，還是要核可——這樣才不會有人靠拆單規避。

如果主管覺得有問題，會**駁回**並寫原因。單子回到你手上，改完可以重新送。駁回後已經投的票會清空，重新來過。

**④ 填採購日**

核可通過 ≠ 已經花錢。**東西真的買了、錢真的付了，才回來填採購日。**

可以填的人：主管、Admin、**會計**。

**⑤ 自動變成支出**

填了採購日的當下，這張單的每個項目**各自變成一筆支出**，出現在支出頁。

```
請款單 PR-202608-003
├─ 冷氣濾網   $1,200  修繕維護  14B5    ──►  支出：8/15 冷氣濾網 $1,200
├─ 遙控器     $  450  備品      14B5    ──►  支出：8/15 遙控器  $  450
└─ 工資       $2,000  修繕維護  14B5    ──►  支出：8/15 工資    $2,000
```

**不用再手動輸入一次。**

## 四、支出頁

左側選單「📒 支出」。管家看不到這一頁。

上面三張卡片：

- **總支出** — 目前篩選條件下的總金額
- **會計科目分項** — 錢花在哪些類別（修繕？備品？水電？）
- **房源分項** — 哪個房源花最多

下面是明細，可以照日期、科目、用途、支付方式篩選，也能下載 Excel。

### 兩種支出

| 來源 | 標記 | 能不能刪 |
|---|---|---|
| 請款單連動 | 項目旁有藍色「請款」標籤 | **不能刪**（只有 Admin 可以）|
| 直接新增 | 無標記 | 可以刪 |

**為什麼連動的不能刪？**

因為那筆錢是走完兩票核可才花出去的。如果一個人就能把紀錄刪掉，那兩道核可等於白設。而且刪掉之後請款單還是顯示「已採購」，支出這邊卻沒了，**兩邊對不起來而系統不會提醒你**——這種帳最難查。

要修正金額請用「編輯」，不要刪。

## 五、誰能做什麼

```
                    看訂單  看營收  請款  核可  填採購日  看支出  系統設定
   管家    🧹        ✓       ✗      ✓     ✗      ✗        ✗       ✗
   會計    📗        ✓       ✓      ✓     ✗      ✓        ✓       ✗
   主管    👔        ✓       ✓      ✓     ✓      ✓        ✓       ✗
   Admin   🔑        ✓       ✓      ✓     ✓      ✓        ✓       ✓
```

### 說明

**管家**
日常記錄訂單、清潔、看評價。可以請款，但**只看得到自己送的單**，也看不到公司整體的營收和支出。

**會計**
帳務作業。看得到訂單、營收、支出，可以填採購日、整理支出。

> **會計不能核可請款單。** 這是刻意的——請款的人、核可的人、記帳的人要分開，這樣才叫內控。會計負責「錢花掉之後把帳做對」，不負責「決定要不要花」。

**主管**
核可的其中一票。也能做會計能做的所有事。

> **不能核可自己送的單。** 主管自己請款，那一票要別的主管來投。

**Admin（系統管理員）**
核可的另一票，加上人員、房源、帳號等系統設定。

## 六、常見情況怎麼辦

### 「單子填錯了，還沒送出」
直接編輯，或刪掉重開。草稿狀態隨你改。

### 「送出了才發現填錯」
請主管駁回，單子會回到你手上，改完重送。

### 「已經核可了才發現金額錯」
核可過的單**不能改也不能刪**。這是刻意的——已經批准的東西不該偷偷變動。

處理方式：照原本的採購，然後在支出頁調整那筆金額，並在備註寫明原因。差額大的話跟主管說一聲，另外開一張單處理。

### 「採購日填錯了」
可以改。改了之後對應的支出日期會跟著調整，**不會重複產生新的支出**。

### 「東西後來沒買」
目前系統**沒有撤銷採購的功能**。如果還沒填採購日，就放著別填。已經填了的話，請 Admin 協助處理。

### 「我看不到支出頁」
你是管家角色。支出資訊只開放給會計以上。

### 「核可按鈕點不下去」
三種可能：這張單是你自己送的、你的那一票已經投過了、或你是會計（會計不核可）。

### 「營收報表的數字怪怪的」
不要改報表，去看**訂單**。報表是從訂單算出來的，訂單對了報表就對了。

## 八、三個原則

**1. 用途一定要填對。**
房源分項統計、之後要算單一房源的損益，全靠這一欄。

**2. 系統自動算的東西不要手動改。**
營收報表、契約的月租單、請款連動的支出——這些都是算出來的。要改就改源頭。

**3. 核可是為了保護你。**
兩票核可不是不信任，是讓花錢這件事有紀錄、有人共同承擔。事後有疑問時，單子上寫得清清楚楚是誰在什麼時候點頭的。
